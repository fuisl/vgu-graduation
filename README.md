# VGU Graduation

A digital companion for the VGU graduation ceremony: personalized invitations, RSVP, memories, event utilities, live translation, and a lasting cohort archive.

> Status: project scaffold. See `AGENTS.md` and `docs/` before implementing features.

## Development

`pnpm install && pnpm dev` runs `apps/web`, `apps/api` and `apps/docs` together. See `docs/development/local-development.md` for Postgres setup, environment files, and trying the API by hand with the [Bruno](https://www.usebruno.com) collection at `dev/bruno/`.

## Principles

- Invitation first.
- Mobile first and resilient at the venue.
- Local-first for private/event data where practical.
- 90% restraint, 10% spectacle.
- GitHub is the source of truth for work; repository docs are the source of truth for durable product and engineering knowledge.
