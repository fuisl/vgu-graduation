## Defaults
Mobile-first; primarily monochrome; small radii; borders/spacing before shadows; one focal visual effect; reuse `packages/ui`; preserve reduced motion.
Motion must communicate state, space, physical behavior or narrative progression.
3D is reserved for hero storytelling, the personalized badge and deliberate cohort visualizations.
Copy is restrained, confident, warm, concise and slightly technical.
If a new visual pattern is required, do not invent it silently: reuse the nearest established pattern or request human review.
