# Visual Philosophy
GRAD '26 combines engineering precision with the emotional weight of graduation.
## Character
Precise, quiet, technical, editorial, experimental, warm without becoming sentimental.
## References
- Vercel Ship: composition, restraint, event identity, selective 3D spectacle.
- Firecrawl: developer character, ASCII/pixel motifs, technical texture.
- Linear-like admin surfaces: hierarchy and utility.
References are inspiration, not templates. Approved GRAD screens eventually supersede them.
## Hierarchy
Prefer **typography → whitespace → border → surface → motion**.
## Core rule
**90% restraint. 10% spectacle.** Reserve WebGL, particles, morphing and cinematic motion for intentional narrative moments.
