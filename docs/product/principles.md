# Product Principles
1. **Invitation first.**
2. **One experience, not many apps.** The invitation/pass connects event utilities.
3. **90% restraint, 10% spectacle.**
4. **Physical ↔ digital.** Phones, displays, camera and prints reinforce one event.
5. **Local ownership.** Private/event data remains under project control.
6. **Graceful failure.** 3D, printer or translation failure must not break critical flows.
7. **Archive quality.** Preserve originals privately; serve optimized derivatives.
