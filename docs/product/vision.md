# Product Vision

GRAD '26 should feel less like visiting a website and more like receiving, attending, and remembering an event.

## Experience arc

**Before:** personalized invitation → RSVP → calendar/directions → digital pass.
**During:** camera → live translation → wishes → event displays → optional photo printing.
**After:** curated gallery → cohort timeline → yearbook/memory archive.

## Users

- Internal graduates/admins.
- Individually addressed guests; one guest may be invited by multiple graduates.
- Anonymous visitors browsing selected public experiences.

## Success

Invitation ships first, ceremony utilities survive imperfect venue conditions, and the archive remains meaningful afterward.
